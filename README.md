# Programmation C++ (2A)

Supports de cours C++ : classes, gestion mémoire, opérateurs, héritage & polymorphisme, templates.

👉 **Le cours en ligne : https://allali.github.io/emmk_i2_cpp/**

## Navigation

| Touche | Action |
|---|---|
| `→` / `Espace` | étape ou diapo suivante |
| `←` | étape ou diapo précédente |
| `M` | sommaire |
| `O` | vue d'ensemble et recherche |
| `F` | plein écran |
| `T` | thème clair / sombre |
| `?` | aide |

## Contenu du dépôt

Site 100 % statique (HTML, CSS, JavaScript, sans dépendance ni compilation) :

- `index.html` : page du cours ;
- `assets/` : moteur de présentation ;
- `slides/` : contenu, un fichier par chapitre.

Pour le consulter hors ligne, ouvrir `index.html` dans un navigateur.
